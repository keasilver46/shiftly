# Shiftly – MVP 화면 구성

근무 스케줄 & 급여 정산 서비스의 MVP 화면 정의.
역할은 **관리자**와 **직원** 두 가지. 직원 화면은 모바일 웹, 관리자 화면은 데스크탑 기준.

---

## 전체 화면 흐름

```
로그인
 ├─ [직원]  → 홈(출퇴근) ─ 내 근무표 ─ 내 근무기록
 └─ [관리자] → 대시보드 ─ 근무표 편집 ─ 직원 관리
```

## 개발 순서

1. 로그인
2. 직원 – 홈(출퇴근)
3. 관리자 – 대시보드
4. 직원 – 내 근무표
5. 관리자 – 근무표 편집 (가장 어려움, 마지막)

> 5번은 처음엔 드래그 없이 **셀 클릭 → 드롭다운 선택** 방식으로 만들고, 드래그는 나중에 붙인다.

---

## 1. 로그인 (공통)

```
┌────────────────────────────┐
│                            │
│        Shiftly (로고)      │
│    근무 스케줄 & 급여 정산    │
│                            │
│  이메일  [______________]   │
│  비밀번호 [______________]   │
│                            │
│  [        로그인        ]   │
│                            │
│  테스트 계정으로 체험하기 ▼   │
│   · 관리자로 로그인          │
│   · 직원으로 로그인          │
└────────────────────────────┘
```

**포인트**
- 포트폴리오용이므로 **테스트 계정 바로 로그인** 버튼 필수. 면접관은 회원가입을 하지 않는다.
- 로그인 성공 시 역할에 따라 직원 홈 / 관리자 대시보드로 분기.

---

## 2. 직원 – 홈 (출퇴근)

모바일 세로 화면 기준.

```
┌──────────────────┐
│ 안녕하세요, 김직원  │  ≡
│ 2026.09.22 (월)   │
├──────────────────┤
│ 오늘 근무          │
│ 09:00 ~ 18:00     │
│ 매장 A · 오픈조     │
├──────────────────┤
│                  │
│    14 : 32 : 07   │  ← 현재 시각, 크게
│                  │
│  [   출근하기   ]  │  ← 상태 따라 출근/퇴근 토글
│                  │
│  출근 09:02 완료 ✓ │
├──────────────────┤
│ 이번 주 근무시간    │
│ ████████░░ 32h/40h│
│ 연장 2h · 야간 0h  │
├──────────────────┤
│  홈  │ 근무표 │ 기록 │  ← 하단 탭
└──────────────────┘
```

**포인트**
- 출근/퇴근 버튼 하나가 화면의 주인공.
- 버튼 상태: `출근 전 → 출근하기` / `근무 중 → 퇴근하기` / `퇴근 완료 → 비활성`.
- 주간 근무시간 진행 바로 **주 52시간 규칙 검증** 기능을 자연스럽게 노출.

---

## 3. 직원 – 내 근무표

```
┌──────────────────┐
│ ◀  2026년 9월  ▶  │
├──────────────────┤
│ 월  화  수  목  금  토  일 │
│ 1   2   3   4   5   6   7 │
│ 오  오  -   마  마  -   -  │
│ 8   9  10  11  12  13  14 │
│ 오  오  오  -   마  마  -  │
│ ...                      │
├──────────────────┤
│ 9/22 (월) 선택됨   │
│ 09:00 ~ 18:00     │
│ 매장 A · 오픈조     │
│ 함께 근무: 이직원, 박직원│
├──────────────────┤
│  홈  │ 근무표 │ 기록 │
└──────────────────┘
```

**범례**: `오` = 오픈(09~18), `마` = 마감(14~23), `-` = 휴무

**포인트**
- 월 단위 캘린더, 날짜 탭 시 하단 상세 갱신.
- 같은 날 같은 조에 배정된 동료 표시.

## 4. 관리자 – 대시보드

데스크탑 기준. 좌측 사이드바 + 본문.

```
┌──────┬───────────────────────────────────────────┐
│ 로고  │  대시보드                    2026.09.22  관리자▼│
│      ├───────────────────────────────────────────┤
│▶대시보드│ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐│
│ 근무표 │ │출근 12/15│ │지각 2   │ │미출근 1  │ │52h 임박 3││
│ 직원   │ └─────────┘ └─────────┘ └─────────┘ └─────────┘│
│ 정산   │                                            │
│      │  오늘 근무 현황                               │
│      │ ┌──────┬──────┬────────┬────────┬─────────┐ │
│      │ │ 이름  │ 조    │ 예정   │ 출근   │ 상태     │ │
│      │ ├──────┼──────┼────────┼────────┼─────────┤ │
│      │ │김직원 │ 오픈  │ 09:00  │ 09:02  │ 근무중   │ │
│      │ │이직원 │ 오픈  │ 09:00  │ 09:15  │ 지각    │ │
│      │ │박직원 │ 마감  │ 14:00  │  -     │ 예정    │ │
│      │ └──────┴──────┴────────┴────────┴─────────┘ │
│      │                                            │
│      │  주의 필요                                   │
│      │  ⚠ 최민수 – 이번 주 49h, 금요일 근무 시 52h 초과  │
│      │  ⚠ 정수진 – 미출근 (09:00 예정)                │
└──────┴───────────────────────────────────────────┘
```

**구성**
- 상단 요약 카드 4개: 출근 인원 / 지각 / 미출근 / 52시간 임박
- 오늘 근무 현황 표: 이름, 조, 예정 시각, 실제 출근, 상태
- 주의 필요 목록: 규칙 위반 임박, 미출근 등

**포인트**
- 카드 + 표 + 경고 목록은 백오피스 표준 구성.

## 5. 관리자 – 근무표 편집 (핵심 화면)

```
┌──────┬───────────────────────────────────────────┐
│ 로고  │  근무표 편집   ◀ 9월 4주 (22~28) ▶   [저장] │
│      ├───────────────────────────────────────────┤
│ 대시보드│         월    화    수    목    금    토    일 │
│▶근무표 │ ┌──────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│ 직원   │ │김직원 │오픈 │오픈 │  -  │마감 │마감 │  -  │  -  │
│ 정산   │ │ 32h  │     │     │     │     │     │     │     │
│      │ ├──────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│      │ │이직원 │오픈 │  -  │오픈 │오픈 │  -  │마감 │마감 │
│      │ │ 40h  │     │     │     │     │     │     │     │
│      │ ├──────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│      │ │최민수 │마감 │마감 │마감 │마감 │마감 │오픈 │  -  │
│      │ │ 49h ⚠│     │     │     │     │     │ 🔴  │     │
│      │ └──────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘
│      │                                            │
│      │  근무 유형   [오픈 09-18] [마감 14-23] [휴무]   │
│      │  ← 여기서 드래그해서 셀에 놓기                   │
│      │                                            │
│      │  ⚠ 최민수: 토요일 배정 시 주 52시간 초과 (57h)   │
└──────┴───────────────────────────────────────────┘
```

**동작**
- 행 = 직원, 열 = 요일. 셀에 근무 유형 배정.
- 배정 즉시 왼쪽 주간 합계 갱신, 52시간 초과 시 빨간 표시.
- 저장 전엔 프론트에서 계산, 저장 시 **백엔드가 다시 검증**. 두 결과가 일치함을 보여주는 것이 포인트.

**단계별 구현**
1. 셀 클릭 → 드롭다운으로 근무 유형 선택
2. 주간 합계 + 52시간 경고
3. 드래그 앤 드롭 (선택)

---

## 2단계에서 추가할 화면 (MVP 제외)

| 화면 | 역할 | 내용 |
|---|---|---|
| 내 근무기록 | 직원 | 월별 출퇴근 목록, 연장/야간 시간 합계 |
| 직원 관리 | 관리자 | 목록, 등록/수정, 시급·월급 설정 |
| 정산 | 관리자 | 월 선택 → 직원별 급여 계산 표 → 명세서 PDF 다운로드 |
